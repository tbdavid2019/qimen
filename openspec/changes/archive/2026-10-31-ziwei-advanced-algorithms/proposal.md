# Proposal

## Why

目前系統的紫微斗數模組已具備基礎排盤、未來另一半正緣與男生尺寸速測等特色功能，但在傳統命理專業深度上，格局判定僅有 13 種簡易條件、缺乏成格/破格與古籍出處考證；星曜廟旺平陷與《紫微斗數全書》善本存在細微出入；缺少主流排盤具備的歲前/將前/博士十二神煞體系；且夫妻宮斷語尚未具備深層外形性格畫像與雙人紫微合盤比對能力。

吸收開源社群經過嚴密古籍校訂的精華演算法（基於 MIT 授權的開源成果），能在維持輕量、免構建與零授權風險的前提下，將本專案的紫微斗數專業度提升至大師級水準。

## What Changes

- **34 種正統古籍格局判定引擎**：移植並重構 1100+ 行格局判定知識庫，涵蓋「君臣慶會、紫府同宮、府相朝垣、陽梁昌祿、殺破狼、機月同梁、日月同宮、明珠出海、羊陀夾忌、馬頭帶箭」等 34 種格局，嚴格輸出成立條件（required）、加分條件（bonus）、破格警示（breaking）與古籍出處（source）。
- **夫妻宮深層斷語與雙盤合盤算法**：擴充夫妻宮十四主星與生年四化之深度畫像（外貌特徵、性格盲點、婚期建議、年齡差指引），並新增「雙人紫微命盤合盤評估算法（evaluateZiweiMatch）」，比對雙方命宮主星、夫妻宮投射、四化互照與煞星衝突度。
- **《紫微斗數全書》善本廟旺平陷校驗**：依據《全書》善本與金標準盤校對結果，修正太陰午宮陷、天機辰戌廟、天府辰戌旺等 24 處廟旺陷分歧。
- **歲前十二神、將前十二神與博士十二神煞**：本命態依生年支起將前十二神（將星、攀鞍、歲驛、咸池等）與歲前十二神（歲建、晦氣、喪門、歲破等），並依生年祿存起博士十二神（博士、力士、青龍等），補齊專業排盤神煞層次。
- **端到端五層對齊**：依據專案規範同步更新 Web UI（格局成格/破格彩色標籤、合盤視角、神煞切換）、API（`/api/ziwei/chart`、`/api/ziwei/match`）、CLI（`skills/ziwei-consultant`）、WebMCP 工具定義與文檔。

## Impact

- **Affected Code**: `lib/ziwei.js`（核心排盤擴充）、新增 `lib/ziwei-patterns.js`（34 格局判定庫）、新增 `lib/ziwei-match.js`（雙盤合婚算法）、`app.js`（新增/增強端點）、`views/ziwei.html` & `public/js/ziwei.js`（UI 視覺更新）、`public/js/webmcp.js`（WebMCP 工具註冊）、`skills/ziwei-consultant/`（CLI 支援新參數）。
- **Dependencies**: 零新增外部依賴，純原生 JavaScript 算法實現，保持極速運行與 Vercel Serverless 輕量化。
- **Breaking Changes**: 無破壞性變更；既有 API 欄位完全向下相容，擴充格局詳情、神煞列表與合盤資料。
